Code derived from other projects
--------------------------------

Siril - https://siril.org
  Copyright (C) 2005-2011 Francois Meyer
  Copyright (C) 2012-2026 team free-astro
  License: GNU General Public License, version 3 or later (LICENSE)

  GPU Stacker reproduces the stacking of Siril 1.4 so that its results match Siril's. Code ported
  from Siril:
  - pixel rejection and the weighted mean (stacking/rejection_float.c, stacking/median_and_mean.c,
    algos/sorting.c): gpustacker/engine/reference.py, gpustacker/engine/kernels.py
  - normalization statistics and the background noise estimate (algos/statistics_float.c,
    algos/quantize.c): gpustacker/engine/stats.py, gpustacker/engine/kernels.py
  - normalization coefficients and frame weights: gpustacker/engine/job.py, gpustacker/engine/kernels.py
  - feather masks (stacking/blending.c, opencv/opencv.cpp): gpustacker/engine/masks.py
  - registered sequences and their framing: gpustacker/engine/sequence.py
  The Siril script (siril/GPU Stacker/GPU-Stacker.py) uses Siril's sirilpy module, which comes with
  Siril (GNU General Public License, version 3 or later).

RawTherapee - https://rawtherapee.com
  Copyright (c) 2017-2018 Ingo Weyrich
  License: GNU General Public License, version 3 or later (LICENSE)

  findMinMaxPercentile (rtengine/rt_algo.cc), which Siril uses for its histogram median:
  gpustacker/engine/stats.py

CFITSIO - https://heasarc.gsfc.nasa.gov/fitsio/
  License: LICENSES/LicenseRef-CFITSIO.txt, reproduced at the end of this file

  The FnNoise1 background noise estimate (quantize.c, after algorithms by Richard White at STScI,
